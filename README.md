# JavaScript Sudoku

A Sudoku game built with JavaScript as a practice project to apply the concepts learned so far.

## About the project

This project is a console-style Sudoku game that runs in the browser using `prompt()` and `alert()`.

The player can:

* Select a row and column.
* Enter a number from 1 to 9.
* Place numbers only in empty cells.
* Check numbers against the current row.
* Check numbers against the current column.
* Check numbers against the corresponding 3×3 quadrant.
* See the updated board after each valid move.
* Exit the game at any time.
* Receive a message when the Sudoku is completed.

## Concepts practiced

This project applies several JavaScript concepts:

* 2D arrays
* `for` loops and nested loops
* `while` loops
* `if`, `else if` and `else`
* Functions
* `prompt()` and `alert()`
* Variables and booleans
* String methods such as `trim()` and `toLowerCase()`
* Number conversion with `Number()`
* Logical operators (`&&` and `||`)
* `Math.floor()`
* Array indexing and modification
* Input validation

## How to play

1. Open the project in Visual Studio Code.
2. Open `index.html` with Live Server.
3. The initial Sudoku board will be displayed.
4. Enter the row, column and number requested by the prompts.
5. The game checks whether the number can be placed.
6. Continue until the board is complete or choose the option to exit.
